# 한국 수출입 무역통계 탐색기

관세청 통관실적을 HS Code 기준으로 조회해 수출입 추이와 무역수지를 보는 도구입니다.
공개 데이터만 사용하므로 어디에 올려도 문제가 없습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

인증키 없이 **조회**를 눌러도 샘플 데이터로 화면이 뜹니다. 먼저 눌러보고 구조를 확인한 뒤 키를 넣으세요.

## 인증키 발급

1. [공공데이터포털](https://www.data.go.kr) 회원가입
2. **관세청_품목별 국가별 수출입실적(GW)** 검색 후 활용 신청 — 개발계정은 자동 승인됩니다
3. 마이페이지 → 개발계정 → **일반 인증키(Decoding)** 복사
4. 앱 왼쪽 사이드바에 붙여넣기

개발계정 트래픽은 하루 10,000건입니다. 앱이 결과를 1시간 캐시하므로 같은 조건을 다시 조회할 때는 요청이 나가지 않습니다.

## 데이터 읽을 때 주의할 점

- 금액 단위는 **천 달러**(US$1,000), 중량은 **kg**입니다
- 수출은 **FOB**, 수입은 **CIF** 기준이라 같은 거래도 양쪽 금액이 다르게 잡힙니다
- 매월 15일경 전월까지 자료가 현행화됩니다. 최근 1~2개월 수치는 이후 정정될 수 있습니다
- HS Code는 6단위까지 국제 공통, 10단위는 한국 고유(HSK)입니다
- 조회 결과에 기간별 행과 총계 행이 섞여 들어오므로, 앱에서 자동으로 분리합니다

## 구조

```
app.py              화면 구성과 조회 흐름
theme.py            팔레트·타이포그래피, 무역수지 저울 컴포넌트
hs_presets.py       자주 보는 HS Code 목록
country_codes.py    상대국 ISO 코드
sample_data.py      인증키 없을 때 쓰는 가짜 시계열
```

HS 프리셋은 `hs_presets.py`에 딕셔너리 하나만 추가하면 늘어납니다.

## 더 해볼 만한 것

- 국가별 비교 — 같은 HS Code를 여러 상대국으로 동시 조회해 점유율 변화 보기
- 단가 추정 — 금액을 중량으로 나눠 kg당 단가 추이 그리기. 원자재 가격 흐름과 겹쳐 보면 재미있습니다
- 관심 품목 저장 — 자주 보는 조합을 로컬 파일에 저장해 두고 한 번에 불러오기
